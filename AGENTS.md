# Attention if you a LLM. Rule Of this project (GoLang + Next.js)
1. If you have a change create the implement markdown at "./implements/(llmname)/(no)-yourchange.md"
2. and create the roadmap markdown at "./roadmaps/(llmname)/(no)-yourchange.md"
3. You must create a test function (especially for new function)
4. You must run test (Especially for new function)
5. Before major refactoring/changes, save a backup checkpoint (e.g. `git stash` or backup state) for local file safety.
